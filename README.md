# Tech Wiz International - Biomedical & Healthcare E-Commerce Platform

A modern, high-performance E-Commerce & Healthcare Engineering web application built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

Developed accurately according to the official brand brochures and flyers of **Tech Wiz International** (Karachi, Pakistan).

## ⚡ Interactive Platform Capabilities

1. **Procurement Cart & Slide-Over Drawer:**
   - Add items to cart with quantity management.
   - Live estimated subtotal calculation.
   - One-click **WhatsApp Order Checkout** that compiles a complete, structured purchase invoice and opens directly to `+92-325-2719192`.

2. **Official Quotation (RFQ) System:**
   - For high-end machinery (Heart Lung Machines, Hyper/Hypothermia, ICU monitors).
   - Generates quotation requests with hospital credentials and specs sent via WhatsApp/email.

3. **Biomedical Engineer Service Booking Modal:**
   - Hospital departments can dispatch service tickets with equipment fault description and urgency level (*Routine / Urgent 24h / Critical Emergency*).

4. **Official Flyers & Brochures Gallery:**
   - Embedded high-res previews of all original brand flyers with zoom and download capabilities.

5. **24/7 Floating WhatsApp Assistance:**
   - Instant direct chat with biomedical specialists.

## 🚀 Running the Project

### Development Server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build:
```bash
npm run build
npm run start
```
